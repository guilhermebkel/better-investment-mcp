# FNET: Spike on FII monthly reports, access viability, and architectural decisions

Date: 2026-11-08. Status: accepted. The owner approved public automated access to FNET and accepted the CNPJ dependency on 2026-11-08 14:29 BRT. The FNET filing and document adapters are implemented in this PR (#12).

Issue #12 asks whether monthly reports for Real Estate Investment Funds (FIIs) can be listed and downloaded from B3 FNET infrastructure by an automated client without login or captcha, whether the downloaded PDFs produce usable text with `DocumentTextService`, and what architectural design choices exist for fund identification, provider dispatching, and chunk paging.

## Owner Decisions

On 2026-11-08 14:29 BRT, the owner reviewed the spike results and decided:
1. **Access terms**: Accept the absence of explicit terms on FNET and authorize implementing automated public reading.
2. **CNPJ dependency**: Accept that `FnetAdapter` depends on `assets.legal_id` and fails clearly with an informative error when CNPJ is missing, documenting that the current asset catalog does not yet populate it. No new seed tables, writing tools, or web scrapers are added in this PR.
3. **Scope**: Implement FNET as an opt-in provider under existing configuration (`INVESTMENT_MCP_FILINGS_PROVIDER=BR:fnet` and `INVESTMENT_MCP_DOCUMENTS_PROVIDER=BR:fnet`), maintaining standard catalog semantics.

### 1. HTTP Access Verification
- **Listing**: GET requests to `https://fnet.bmfbovespa.com.br/fnet/publico/pesquisarGerenciadorDocumentosDados?d=1&s=0&l=30&tipoFundo=1&cnpjFundo={cnpj}&o[0][dataEntrega]=desc` returned HTTP 200 with JSON document records without login, cookies, or captcha challenges.

### 2. Table and Text Usability Audit

To verify that extracted text is usable and financial figures remain intact and associable, a specific page containing financial tables was selected from each PDF. The text extracted by `DocumentTextService.extractPdf` (`unpdf`) was compared against an independent reference extraction using `pdftotext -layout`:

- **HGLG11 (Page 5, "Comentários da Gestão e Indicadores Financeiros")**:
  - Sample labels and values: `Patrimônio Líquido*` (`R$ 7,5 bilhões`), `Cota Patrimonial*` (`R$ 165,48`), `Valor de Mercado*` (`R$ 6,7 bilhões`), `Cota de Mercado*` (`R$ 147,95`), `resultado de` (`R$ 0,89/cota`).
  - Quality: `unpdf` serializes labels followed by values in block reading order. Numbers and decimals are intact.
- **KNRI11 (Page 1, "Quadro Resumo de Indicadores")**:
  - Sample labels and values: `PATRIMÔNIO LÍQUIDO` (`R$ 4.602.278.866,50`), `VALOR TOTAL DE MERCADO` (`R$ 4.244.709.074,56`), `TOTAL DE COTAS` (`28.204.047`), `COTA PATRIMONIAL` (`R$ 163,18/cota`), `DISTRIBUIÇÃO MENSAL` (`R$ 1,10/cota`).
  - Quality: In the `unpdf` stream, values precede labels due to drawing stream order (`R$ 4.602.278.866,50 PATRIMÔNIO LÍQUIDO1`). Numbers and labels are extracted without corruption.
- **MXRF11 (Page 2, "Destaques do Mês")**:
  - Sample labels and values: `Rendimento Distribuído` (`R$ 0,10`), `Yield Mensal` (`1,09%`), `Yield Anualizado` (`13,90%`), `% do CDI no período*` (`118,51%`), `CNPJ` (`97.521.225/0001-25`).
  - Quality: Extracted as consecutive sequences (values row followed by labels row). Numbers are intact; association requires positional column correlation.
- **XPLG11 (Page 1, "Comentário do Gestor e Indicadores Chave")**:
  - Sample labels and values: `distribuição de` (`R$ 0,82/cota`), `dividend yield anualizado de` (`10,64%`), `fechamento do mês` (`R$ 92,51/cota`), `pagamento dos rendimentos` (`15/10/26`).
  - Quality: Inline metrics within text blocks have direct syntactic attachment between labels and values.
- **VISC11 (Page 3, "Visão Geral do Fundo")**:
  - Sample labels and values: `Valor de Mercado da Cota¹ (30-09-2026)` (`R$ 102,16`), `Valor Patrimonial da Cota (30-09-2026)` (`R$ 115,79`), `Quantidade de Cotas` (`28.828.640`), `Número de Cotistas (30-09-2026)` (`346.772`), `CNPJ` (`17.554.274/0001-25`).
  - Quality: Direct pairwise label-value ordering. High legibility and direct associability.

**Audit conclusion**: 5/5 PDFs (100%) meet the usability threshold (>=4/5). Tabular visual formatting is flattened to linear text streams; numerical values and labels are fully preserved and associable. Linear extraction does not guarantee 2D visual table alignment; no OCR is performed on image-only layers.

## StatusInvest Observations

During the research spike, StatusInvest endpoints mentioned in initial discussions were probed:
- `https://statusinvest.com.br/home/mainsearchquery?q=HGLG11` returned `HTTP 403 Forbidden` under standard request headers.
- `https://statusinvest.com.br/fii/getassetreports?fiiId=130&documentCategory=6` returned an empty JSON array `{"total":0,"initialList":[]}`.

Probing this single endpoint does not replicate StatusInvest's true multi-step client workflow (which resolves search query to parent entity, then fund identifier and specific document categories). Returning an empty response on a single probe does not prove total platform unavailability, and a single 403 response does not establish complete site behavior. Because FNET provides official, direct, and unauthenticated public endpoints, no further reverse-engineering of StatusInvest was performed.

## Implementation Details in `FnetAdapter` and `FnetDocumentAdapter`

The adapters implemented in this PR enforce strict security boundaries and operational contracts:

1. **Document Security & Limits**:
   - `FnetDocumentAdapter.MAX_DOCUMENT_BYTES`: 20 MiB (`MAX_DOCUMENT_MIB = 20`).
   - `FnetDocumentAdapter.TIMEOUT_MS`: 60,000 ms.
   - Strict URL parsing via `new URL()` enforcing `https:`, exact host `fnet.bmfbovespa.com.br`, allowed paths (`/fnet/publico/exibirDocumento` and `/fnet/publico/downloadDocumento`), and positive integer `id`.
   - Rejects unexpected ports and embedded credentials without leaking sensitive strings in error messages or database logs.
   - Verifies `%PDF` header signature before storing bytes; rejects vendor HTML error pages.
2. **Listing & Pagination**:
   - `FnetAdapter.PAGE_SIZE = 30` (matching verified spike page size).
   - `FnetAdapter.MAX_PAGES = 50`.
   - Pagination targets `recordsFiltered ?? recordsTotal` and advances by rows returned.
   - Throws explicit non-silent errors naming FNET, ticker, and records fetched on premature empty pages or when reaching page limits.
   - Preserves all versions delivered by FNET (active and inactive).
   - Preserves raw `category` (null if missing) and raw fund description in `subject`.
3. **Legal ID Dependency**:
   - Injected with a store-backed `LegalIdLookup` that queries `SELECT legal_id FROM assets WHERE market = ? AND ticker = ?`.
   - Fails clearly with zero HTTP requests when `assets.legal_id` is null or missing.
