One SQL tool for Brazilian market data.

better-investment-mcp is an open-source MCP server that gives your AI agent Brazilian prices, dividends, fundamentals, filings and macro series. It fills a local DuckDB cache on demand, and the agent answers with one read‑only SELECT.

Star on GitHub

$npx -y better-investment-mcp init

Every query names its asset. No exceptions.

The server reads the filter, loads what is missing or expired, then runs the query. A query without it is refused, and the answer says which filter to add.

  • Literal filters onlyCompared with = or IN against literal text, up to 50 assets per query.
  • asset_metrics also needs a metricA metric is group.name, like fii.net_worth or macro.value. The unit comes on every row.
  • Joins work, filters do not travelEach asset table in a join needs its own asset_id filter. The guard reads the query with DuckDB's own parser.

Four tools. Three only read.

Nothing in the server changes anything outside its own cache file, except one notice: `notify_load_finish` sends a POST to an https address you give when a background load finishes (ADR 0028). That rule lives in code with a test, not in a prompt.

get_overview

The server's usage notice, the tables, and what is loaded now. Call it first.

get_guide

A short guide for one topic of query_sql: sql, search, sources or limits.

One command, then ask.

No account or key is needed for the open data sources. You only need an MCP client such as Claude, Cursor or Codex.

Add this to the MCP servers of your client.

{
  "mcpServers": {
    "better-investment": {
      "command": "npx",
      "args": ["-y", "better-investment-mcp"]
    }
  }
}

The client starts the container. The cache lives in a named volume.

docker run -i --rm \
  -v better-investment-cache:/cache \
  ghcr.io/guilhermebkel/better-investment-mcp

Runs on your machine. Every request must send a bearer token of at least 8 characters.

docker run -d --name investment-mcp \
  -p 127.0.0.1:3100:3100 \
  -e INVESTMENT_MCP_TRANSPORT=http \
  -e INVESTMENT_MCP_HTTP_HOST=0.0.0.0 \
  -e INVESTMENT_MCP_HTTP_TOKEN='your-long-random-secret' \
  -v better-investment-cache:/cache \
  ghcr.io/guilhermebkel/better-investment-mcp

Then point the client at http://127.0.0.1:3100/mcp with an Authorization: Bearer header. Put a TLS proxy in front before exposing it beyond localhost.

Point the cache at a folder of your own to keep it between runs. Deleting the file loses nothing: the next query loads the data again. Print your client config with npx -y better-investment-mcp init.

Private by construction. Data, never instructions.

Writes only to its own cache

Each vendor in the sources list is the only place it fetches from. Nothing is sent anywhere else.

Token on every request

In HTTP mode, /mcp needs the bearer token on every address. It is never returned or logged.

Filings are data

Text from reports and other third-party documents is data, never an instruction to your agent.

Not investment advice. The output describes and locates information. It never recommends what to buy or sell. This is an unofficial project, not affiliated with B3, CVM, Yahoo or any other data vendor.

Questions worth asking first.

Does it tell me what to buy?
No. It describes and locates information. It is not investment advice, a recommendation or an analysis of what to buy or sell.
Is it ready for daily use?
It is a work in progress. The server runs and its tools answer, but the data behind them arrives issue by issue. The sources list and the repository show what exists today.
Why does a query say a source is blocked?
A site that refuses this server, like StatusInvest answering with a Cloudflare challenge, is reported in the loaded report with its error. The server does not bypass it. Other providers still answer, and a fallback is used where one is set.
Can I delete the cache?
Yes. It is one DuckDB file and it is disposable. The next query loads the data again. One cache file serves one running server at a time.
Which AI clients work?
Any client that speaks MCP, such as Claude, Cursor and Codex. Run init to print the configuration for each.

Read the data. Keep the judgment yours.
